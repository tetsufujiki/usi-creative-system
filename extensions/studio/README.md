# Studio Extension

> Status: Draft
>
> This document defines the Studio extension for studio.united-studio.com.

## 1. Role

`studio.united-studio.com` は、空間、設備、制作環境、レコーディングスタジオとしての信頼を伝えるExtensionである。

USI新河岸音楽工務所として、東京・板橋で音をつくる場所と、その場所に備わる技術、空気、距離を表す。

## 2. Primary Feeling

`Crafted Trust / Deep Focus`

訪問者が、設備情報を読む前から制作へ集中できる空間を感じ、その後に写真と事実によって任せられると判断できる状態を目指す。

## 3. Audience

- レコーディング、ミックス、制作環境を探しているアーティスト。
- 録音品質と設備を比較している制作者。
- 初めてスタジオを利用する人。
- 継続的な制作拠点を探しているクリエイター。

## 4. Visual Language

- 黒背景と深い暗部。
- 実際の空間写真。
- 音響、残響、距離を感じさせる奥行き。
- 写真と光、色場、Atmosphere Engineの組み合わせ。
- 静かな大見出しと、大きな余白。

Atmosphere Engineと空間写真はStudio固有の表現として扱う。UDSL Coreや他Extensionへ強制しない。

## 5. Trust Strategy

信頼は、雰囲気だけで成立させない。

- 実在する空間と設備の写真。
- 住所と電話番号。
- 価格帯とサービス範囲。
- Structured dataとmetadata。
- FAQ。
- 予約、詳細、問い合わせへの明示的な導線。

## 6. Content Strategy

機材一覧だけでなく、どのような空間で、どのように録音や制作が進むかを示す。

写真は飾りではなく、空間、設備、距離、実在性を説明する。機材、平面、工程、担当者の情報は、制作判断に必要な順序で配置する。

## 7. Handoff

- `reserve`：空き状況確認と予約実行。
- `rec`：料金、録音サービス、詳しい対応範囲。
- `united-studio.com`：会社情報と全体像。
- Contact：個別の制作相談。

## 8. Avoid

- UtattemitaのようなPOP方向へ寄せすぎる。
- 機材説明だけのサイトにする。
- 空間写真を飾りで終わらせる。
- 予約導線を曖昧にする。
- 暗さそのものをStudio人格だと誤解する。

## 9. Notes for united-studio.com

本体サイトでは、Studioを「設備のある場所」だけでなく、音をつくる空間と専門性の入口として見せる。

黒背景やAtmosphere Engineを本体全体へ持ち込むのではなく、Studioへの入口で空間の深さと静かな信頼へ表情を切り替える。
