# Utattemita Extension

> Status: Draft
>
> This document defines the Utattemita extension for utattemita.united-studio.com.

## 1. Role

Utattemitaは、`rec` の置き換えではない。「歌ってみたい」という気持ちを、空き状況の確認や相談へ進めるための心理的な入口である。

情報を網羅するより、初見ユーザーが「自分にもできそう」と感じ、次の行動を選べる状態をつくる。

## 2. Primary Feeling

`Playful Confidence`

楽しさによって緊張がやわらぎ、自分にも一歩目を踏み出せそうだと思える状態。単なるExcitementや、教室的な安心感ではない。

## 3. Audience

主対象は20代女性を中心とする、初見の「歌ってみた」検討ユーザーである。

ただし、対象者をピンク、かわいい表現、若者言葉へ単純化しない。投稿する人だけでなく、自分のために一曲を残したい人も含める。

## 4. Visual Language

- POP / FUN / 攻め。
- うたみた・投稿カルチャー。
- 写真主役ではなく、タイポグラフィとグラフィック主役。
- シアン背景、太い黒文字、ピンクCTA。
- ステッカー感、グリッド、ポスター感。
- HEROで安心感を出しすぎず、後半で静かな信頼へ移る。

HEROの中心コピー：

> 歌うだけで、
>
> 一曲になる。

## 5. Copy Strategy

コピーは短く、話しかけるように書き、行動のハードルを一段だけ下げる。

- 好きな曲を、自分の声で。
- 録音もミックスも一緒に進むから、あなたはマイクの前で歌うだけ。
- その声、録ってみよう。
- 空き状況・料金を見る。
- 見るだけでも大丈夫です。

「初心者でも簡単」「プロ品質保証」「上手くなってから」「まずはボイトレ」の方向へ寄せない。

## 6. Sample Strategy

サンプルは大量掲載しない。上手い作品例や実績展示ではなく、実際の2時間セッションのテンポを理解するために使う。

古い映像でも体験理解に役立つなら使用できる。高完成度サンプルが必要な場合は `rec`、`studio`、将来の `works` へ引き渡す。

## 7. Trust Strategy

HEROで写真による安心を主役にしない。信頼は、Session、Price & Flow、FAQ、footer、metadata、外部ハンドオフで戻す。

### BRING ONLY / 必要なのはこれだけ

準備物を短く示し、すべてを一人で決めてから来る必要がないことを伝える。

### Price & Flow

- 2時間から。
- エンジニア付き。
- 録音・ミックス・マスタリング。
- 当日完成。
- 空きを見てから決められる。

操作UIはUtattemita人格とし、favicon、metadata、footer、copyrightはUnited Studio人格を担う。

## 8. Handoff

- `reserve`：空き状況・料金確認と予約実行。
- `rec` FAQ：細かい条件と予約前の質問。
- LINE：個別相談。
- `studio`：設備、空間、録音環境。

移動先と、そこでできることをCTA付近で明示する。

## 9. Avoid

- ピアノ教室感。
- アイボリー中心の安心感。
- 初心者向け講座感。
- 写真で安心させるHERO。
- サンプルの大量掲載。
- ボイストレーニングを必須のように見せる。
- 詳細説明を抱え込みすぎる。
- `rec` と同じ情報順序へ戻す。

## 10. Notes for united-studio.com

本体サイトでは、Utattemitaを「録音サービス」の一項目ではなく、歌いたい気持ちから始まる創作入口として見せる。

UtattemitaのPOP人格を本体全体へ広げず、入口で表情を切り替える。帰属と信頼はUnited Studio人格で維持する。
