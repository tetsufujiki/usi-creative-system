# Yosakoi Extension

> Status: Draft
>
> This document defines the Yosakoi extension for yosakoi.united-studio.com.

## 1. Role

Yosakoiは、制作実績、継続性、祭りの熱量を伝えるExtensionである。

歴代作品、制作思想、チームとの関係を、現在まで続く制作の履歴として束ねる。

## 2. Primary Feeling

`Festival Archive / Creative Continuity`

一つの作品の強さだけでなく、複数年にわたる制作の積み重ねと、祭りへ作品が放たれる熱量を感じられる状態を目指す。

## 3. Audience

- よさこいチームと制作担当者。
- 新しい楽曲や演舞制作を検討している人。
- 過去作品を探している関係者と観客。
- United Studioの制作履歴を確認したい人。

## 4. Visual Language

- 祭り、隊列、演舞を由来とする制御された熱量。
- 深い緑、金、橙、紙色。
- 大きな明朝見出し。
- Formation、Surge、Pulse、Flow、Burst、Trace。
- 強い動きの間に置く静止面と読み物。

動きはHEROや見せ場へ限定し、Archiveの探索と作品情報を妨げない。

## 5. Archive Strategy

`作品アーカイブ` は採用したタイトルとして扱う。

作品アーカイブは単なる動画一覧ではない。歴代作品、制作年、チーム、制作思想、祭りの熱量を、探しやすく継続可能な形で束ねる。

`BEHIND THE MUSIC` は、作品の背後にある制作の考え方へつなぐセクションとする。

YouTube埋め込みを初期表示で増やしすぎない。作品量が信頼になる一方、表示の重さと一覧性を管理する。

## 6. Trust Strategy

- 歴代作品の量と継続性。
- 制作年、チーム、曲名が分かる情報構造。
- 作品から制作思想へ進める導線。
- 問い合わせ先とUnited Studioへの帰属。
- 重い埋め込みを避けた安定した閲覧体験。

## 7. Handoff

- Contact / inquiry：新規制作の相談。
- `works`：関連する作品群や将来の横断アーカイブ。
- `united-studio.com`：会社情報と他の創作入口。

## 8. Avoid

- 単なるYouTube一覧にする。
- 初期読み込みが重すぎるページにする。
- 制作年や実績の見通しが悪い構成にする。
- 祭り感がなく事務的になる。
- 熱量を常時Motionだけで表現する。

## 9. Notes for united-studio.com

本体サイトでは、Yosakoiを一つのサービス項目ではなく、長く続く制作文化と作品履歴への入口として見せる。

本体で作品をすべて再掲せず、制作の継続性と熱量を短く示して `作品アーカイブ` と問い合わせへ引き渡す。
